# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in SimplePNS, please report it privately.

**Do not** open a public GitHub issue. Instead, send a description of the issue to [INSERT EMAIL OR CONTACT METHOD].

We will acknowledge receipt within 48 hours and provide a timeline for a fix.

## Scope

Security issues include, but are not limited to:

- Exposure of VAPID private keys
- Timing attacks on encryption
- XSS via notification payloads
- Service worker scope escalation

| Version | Supported |
|---------|-----------|
